# styaldrivingschool.co.uk

Concept home page for Styal Driving School (Jon Bennion), South Manchester and Cheshire. Prospecting asset by Pixel North, not a live website.

- `index.html` is a single static page (no build step).
- Hero photo slot: save a landscape photo as `images/hero.jpg` and it replaces the illustration automatically.
- The page carries `noindex, nofollow` and `_headers` sends `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet`, so it stays out of search engines. Remove both only if the site goes live on the client's domain.
